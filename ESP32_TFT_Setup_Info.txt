================================================================================
                    COSMIC KNOBULATOR - ESP32 TFT SETUP INFO
================================================================================

This file contains all pin configurations, hardware setup, and library information
for the Cosmic Knobulator ESP32 TFT project. Use this as a reference when creating
new projects with the same hardware setup.

================================================================================
HARDWARE COMPONENTS
================================================================================

Main Controller:
- ESP32-S3 development board with PSRAM (required for smooth graphics)
- 2" 240×320 TFT SPI display (ST7789 driver)
- WS2812B addressable LED strip (2 LEDs)
- Vibration motor
- 10k potentiometer (knob)
- Momentary pushbutton
- Breadboard, jumper wires
- (Optional) 3D-printed or DIY kid-safe enclosure

================================================================================
PIN CONFIGURATION - ESP32-S3
================================================================================

TFT DISPLAY (ST7789 Driver):
- TFT_CS    = GPIO 8   (Chip Select)
- TFT_RST   = GPIO 10  (Reset)
- TFT_DC    = GPIO 9   (Data/Command)
- TFT_MOSI  = GPIO 11  (Data Out)
- TFT_SCLK  = GPIO 12  (Clock)
- TFT_LED   = GPIO 13  (Backlight control)

USER INPUT:
- BUTTON_PIN        = GPIO 1   (Main button - INPUT_PULLUP)
- SECOND_BUTTON_PIN = GPIO 3   (Secondary button - INPUT_PULLUP)
- POT_PIN           = GPIO 7   (Potentiometer - ADC1_CHANNEL_7)

OUTPUT DEVICES:
- LED_PIN      = GPIO 2   (WS2812B LED strip data line)
- VIBRATION_PIN = GPIO 5  (Vibration motor control)
- BUZZER_PIN    = GPIO 6  (Buzzer/speaker)

POWER:
- VCC = 3.3V
- GND = Ground

================================================================================
TROUBLESHOOTING TIPS
================================================================================

Common Issues:
1. Display not working: Check TFT_eSPI User_Setup.h configuration
2. LEDs not working: Verify FastLED pin and LED count
3. Buttons not responding: Check INPUT_PULLUP configuration
4. Potentiometer erratic: Ensure stable 3.3V supply
5. Memory issues: Enable PSRAM in board configuration
6. Upload fails: Try different upload speed or hold BOOT button

Performance Optimization:
- Use PSRAM for large sprites
- Minimize redraws with dirty rectangle updates
- Use hardware SPI for TFT communication
- Optimize LED update frequency
